Exporting one page is solved. Exporting a space is not.

Confluence can now hand you a single page as Markdown — the body text, and nothing else. The moment you need the page tree, the attachments, the links between pages, or a filename you can read, that stops being enough. This app exports the whole thing in one pass, and tells you what it had to degrade on the way.

These are different jobs, not two attempts at the same one. If you want one page in a pull request description, use the menu Confluence already gives you. If you are moving a space into a repository, a static site or an LLM pipeline, the rest of this page is about that.

One rule

Degrade, never delete.

Markdown genuinely cannot express everything Confluence can. A merged table cell, a three-column layout, a status lozenge — there is no faithful Markdown for these, and pretending otherwise produces worse output than admitting it.

So the bar is not perfection. The bar is this: after the export, is any information gone that a reader would have had before it? A layout may flatten into paragraphs. It may not lose the second column.

Verified, not claimed

Every release is scored against a public conformance suite — 63 rules, a seed corpus you can install into your own site, and a scorer that reads the output rather than trusting it. The rules, the corpus and the results are all open.

The 63 rules split in two, and the split is the whole point. 46 of them ask whether the text survived — a task’s state, a fence’s language, a macro’s body. 17 ask whether you got your space back — attachments on disk, a filename you can read, a folder tree that matches the page tree.

Confluence’s own export is genuinely good at the first and does not attempt the second: it returns one page’s Markdown and writes no files, so those 17 have nothing to score and are left blank rather than counted as failures. It was measured through the same API the Export menu calls, one page at a time, which is why its date differs from the other two.

Run it yourself before you buy: confluence-markdown-conformance. The repository also holds both exports of the same space, so you can read the difference instead of the scores — GitHub draws one export's Mermaid diagram and prints the other's as text.

It tells you what it degraded

Every run ends with a list of what could not be represented faithfully, and which page it came from. Silence about what was lost is the habit that makes an exporter impossible to trust.

What it exports

  • A page, a page tree, or an entire space in one pass
  • Attachments into attachments/, with body references rewritten to point at them
  • A folder structure that mirrors the page tree
  • Relative links between exported pages; absolute links for anything outside the selection

Runs on Atlassian

Your content never leaves Atlassian infrastructure. The app contacts no external service, stores nothing, and asks only for read access.

The measurement this app came from

Before the app there was a benchmark: a fixed Confluence corpus, 63 rules, and a scorer that names what an export breaks. It is public, MIT licensed, and it scores this app alongside the alternatives, Confluence’s own export included — and it keeps the cases this app fails.
