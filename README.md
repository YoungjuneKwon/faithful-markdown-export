# faithful-markdown-export

The website for **Faithful Markdown Export for Confluence** — an Atlassian Marketplace app
that exports Confluence pages, trees and spaces to Markdown without losing task state, code
block languages, nesting or non-English titles.

Published at <https://youngjunekwon.github.io/faithful-markdown-export/>.

| Page | |
|---|---|
| `index.html` | What the app does and why |
| `docs.html` | How to use it, what the output looks like, what degrades and why |
| `privacy.html` | Privacy policy and security statement (required by the Marketplace listing) |
| `support.html` | How to get help and how to report a lossy export |

Plain HTML and one stylesheet — no build step, no framework, no tracking.

The app is measured against a public conformance suite:
<https://github.com/YoungjuneKwon/confluence-markdown-conformance>
