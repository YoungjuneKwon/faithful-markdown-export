The mark

A carved seal: a tiger, a magpie standing on its back, and the setting-out lines left unerased and running past the border. The magpie is the witness; the construction is not hidden. The studio shows what it can show, with the working left in.

Using the font

The glyph sits at U+E000. It takes the current text colour, so one file covers every colour and every size.

@font-face {
  font-family: "Second Tiger Mark";
  src: url("SecondTigerMark.woff2") format("woff2");
  font-display: block;
}
.st-mark::before {
  font-family: "Second Tiger Mark";
  content: "\E000";
  color: #1D3B53;
}

Limits, stated plainly

  • One colour at a time. The mark is monochrome by design.
  • Below about 32 px the interior stripes crowd together. A reduced glyph for small sizes is not done yet.
  • Screen readers do not announce private-use characters. Pair the glyph with aria-hidden and real text.
